# Dataset and Model Notes

## External datasets

The project README records source citations for the externally sourced datasets:

- `water_quality_dataset1.csv`: Ooko, Cheptegei, and Karume (2026), *Water Quality Dataset from Water Sources in Kenya*, Mendeley Data, Version 2, DOI: https://doi.org/10.17632/575ctg3nnr.2
- `water_potability.csv`: MainakRepositor, *Datasets* repository: https://github.com/MainakRepositor/Datasets/blob/master/water_potability.csv

Please consult the original source pages for licensing and redistribution terms. Citing a source does not automatically grant permission to redistribute its data.

## Water-quality classifier

The classifier uses the features configured in `train_classifier.py` and the dataset `water_quality_dataset1.csv`. Dataset provenance, labels, and external validity should be reviewed before making claims about model generalization. A train/test score does not certify water safety or establish performance on independent laboratory-labelled samples.

## Experimental risk regression

`disease_risk_dataset.csv` is generated by `generate_risk_dataset.py`. The script creates synthetic measurements and a synthetic case-count proxy using a heuristic. This dataset demonstrates a model-training/inference workflow only.

The model output and normalized risk score must not be described as a real disease probability, outbreak forecast, or result derived from actual epidemiological records.

## Sensor readings

Sensor readings are prototype measurements. Comprehensive calibration against reference instruments is not documented. Raw or software-adjusted turbidity ADC readings are not automatically equivalent to NTU.

## Data sharing

Before public release, check the source and license of every dataset. Preserve source attribution and follow any redistribution restrictions. The synthetic risk dataset should remain clearly labelled as synthetic.
